# ТЗ — приложение kids-learning

Обновлено: 30.09.2026, версия 7 (реализация первой сборки; ТЗ v6 без изменений по сути)

## Идея

Учебные материалы у детей в планшетах — как Quill и Duolingo, только со своими медведями и капибарами. Открываются одной кнопкой с главного экрана планшета, у каждого свой пароль. Каждую неделю загружаем то, что сейчас печатаем на бумаге. У родителя-учителя свой вход: уроки целиком с ответами и прогресс детей.

## Пользователи

1. Сын, 7 лет: читает и пишет по-английски, складывает и вычитает в столбик 3–4-значные числа, русский разговорный слабый.
2. Дочь, 10 лет: читает и пишет по-русски и по-английски, складывает и вычитает, знает таблицу умножения.
3. Родитель (мама — учитель, папа помогает): один общий вход.

## Вход

1. Иконка приложения на главном экране планшета (PWA), открывается без браузерных панелей.
2. При первом запуске на планшете родитель один раз вводит семейный пароль (не короче 12 символов). Он расшифровывает материалы и запоминается на этом устройстве.
3. Дальше экран выбора: три карточки с персонажами, у каждой свой PIN-код из 4 цифр. PIN разделяет профили, но материалы им не шифруются: 4 цифры подбираются за секунды.
4. Репозиторий и сайт публичные, поэтому материалы, имена детей и расписание лежат в них только в зашифрованном виде (ключ — семейный пароль).
5. Семейный пароль не попадает ни в код, ни в коммиты: при сборке недели он берётся из переменной окружения FAMILY_PASSWORD в настройках облачного окружения Claude Code.

## Предметы

В приложение идут все предметы из распечаток: русский язык и литература (стихотворение недели), математика (ведётся на русском), английский, наука и логика, французский. Интерфейс каждого предмета — на языке предмета, математика — на русском.

## Контент — недели

Источник — Google Drive, папка «УЧЁБА/09 Приложение/Неделя NN (даты)», в ней 4 Google-документа:
1. «РАСПЕЧАТКА_Неделя N_<ИМЯ> (текст для приложения)» — по одному на каждого ребёнка: тексты детских листов, по страницам. Бумажные PDF печатаются отдельно и в приложение не идут.
2. «УРОКИ_Неделя N_<ИМЯ> (для родителя)» — по одному на каждого ребёнка: уроки целиком: расписание блоков, правила, упражнения, ответы.

Эти документы кладёт на Drive сессия, которая готовит материалы недели.

Сборка превращает их в `week.json` (задания в формате docs/CONTENT_FORMAT.md) и кладёт его в ту же папку как «ПРИЛОЖЕНИЕ_Неделя N (week.json)» — если он там уже есть, берётся он (так неделю можно поправить руками и пересобрать).

Новая неделя загружается в пятницу вечером на следующую неделю. Приложение само показывает текущую неделю по датам, прошлые недели доступны в архиве. Добавление недели — это новые зашифрованные файлы в content/, без правки кода. Исходные тексты в репозиторий не коммитить (временные файлы закрыть в .gitignore).

Каждую пятницу вечером, после загрузки материалов, облачная сессия Claude Code по расписанию (routine) через коннектор Google Drive забирает папку следующей недели, собирает из неё зашифрованный контент и коммитит в main. Если папки нет или идут каникулы — ничего не делает. Текст задания для этой сессии — в README.

Каникулы с 21.12.2026 (дата окончания пока не задана). В каникулы новых уроков нет, серия дней не сгорает, приложение предлагает повторение пройденного. Даты каникул задаются в одном файле настроек.

Лист ребёнка устроен так: день → предмет → страницы. Типы заданий и как их показывать:
1. Правило «Видишь / Пишешь / Почему»: ребёнок выбирает верный вариант из двух, потом видит объяснение (как в Quill).
2. Выбор из вариантов, вписать ответ, найти и исправить ошибку в предложении — с автопроверкой.
3. Пример в столбик: ввод цифр по разрядам с проверкой.
4. Чтение вслух (слоги, слова, числа): карточки по одной, кнопка «послушать» (озвучка ru-RU, en, fr-FR), кнопка «прочитал».
5. Стихотворение недели: текст, словарик, режим заучивания — строки постепенно скрываются по дням (вт прочитать и разобрать, ср первые 4–8 строк, чт целиком с подсказками, пт без подсказок).
6. Задания вне планшета (нарисуй, пропиши в тетради, диктант, письмо на время): карточка «Сделай в тетради», таймер где нужен, кнопка «готово»; родитель подтверждает у себя.
7. Всё, что не получается сделать интерактивным, показывается как страница распечатки, а не выбрасывается.

## Экран ребёнка

«Сегодня» — уроки дня по расписанию, дорожка заданий как в Duolingo. Звёзды, уровни, серия дней подряд, анимация и звук за успех, без штрафов за ошибки. Ошибки возвращаются на повтор.

## Экран родителя

1. Уроки недели целиком из УРОКИ-файлов: расписание, ход урока, ответы.
2. Прогресс каждого ребёнка: что сделано, где ошибки, какие задания «в тетради» ждут подтверждения.

## Стиль

Свои персонажи — медведи и капибары, нарисованные в SVG; у каждого ребёнка свой персонаж-спутник. Ярко, дружелюбно, крупные кнопки, без мелкого текста. Не копировать персонажей, логотипы и узнаваемый дизайн Duolingo и Quill.

## Техника

1. Статический сайт, PWA, работает без интернета после загрузки. Хостинг — GitHub Pages.
2. Прогресс синхронизируется между устройствами: планшеты детей → вход родителя. Выбрать самый простой бесплатный вариант (например, Cloudflare Worker + KV) и описать настройку по шагам для неспециалиста.
3. Без рекламы, внешних трекеров и регистрации.

## Принятые решения

1. Синхронизация: Cloudflare Worker + KV (бесплатно, без регистрации в приложении). Блоки шифруются семейным ключом на устройстве; адрес доступа выводится из пароля; сервер ничего не может прочитать. Слияние — по каждой записи побеждает более поздняя. Настройка по шагам — README.
2. Шифрование: PBKDF2-SHA256 (300 000 итераций, соль в content/manifest.json) → AES-256-GCM. Имена файлов недель — HMAC от ключа, даты и имена снаружи не видны.
3. PIN задаёт родитель в приложении при первом запуске и может сменить в настройках; PIN хранятся хэшами и синхронизируются — пересборка не нужна.
4. Неделю составляет сессия Claude по формату docs/CONTENT_FORMAT.md; сборщик tools/kl.mjs проверяет её (ответы в столбик считает сам), шифрует и обновляет список недель.
5. Приложение без сборки и зависимостей (ES-модули), название на иконке — «Лесная школа».
6. Озвучка — голосами самого планшета (Web Speech API), звуки успеха — синтезом (Web Audio), без внешних файлов и сервисов.

## Открытые вопросы (допущения первой сборки)

1. Имена детей в этом файле заменены на `<ИМЯ>`: репозиторий публичный.
2. «Рамка» экрана сына (приветствие, кнопки дорожки) — на английском, раз он слабо читает по-русски; внутри предметов — язык предмета, как в ТЗ. Меняется полем uiLang профиля.
3. Даты каникул и адрес синхронизации лежат открыто в settings.json («один файл настроек»); ни уроков, ни имён там нет.
4. Уроки, у которых в УРОКИ-файле нет времени (стих ср–чт, пятничный мини-контроль), стоят в конце дня без времени.
5. Диктант «на слух» — задание «в тетради» с подтверждением родителя, слова ребёнку не показываются. «Цифрами под диктовку» — приложение диктует голосом.
6. Деление в столбик: решение — в тетради, в приложении вводится частное по цифрам и показывается проверка умножением.
7. Звёзды: 1 за задание, +1 за исправленную ошибку; новый уровень — каждые 20 звёзд. Серия прерывается только пропуском дня, в который были уроки; выходные, дни без уроков и каникулы её не сжигают.
8. Неделю лучше не пересобирать после понедельника с другим порядком заданий: прогресс привязан к номеру задания.
9. Задание по расписанию (routine) не создано: текст — в README; создаёт владелец (нужны FAMILY_PASSWORD, коннектор Drive и право пушить в main). Время — пятница 20:00 по местному времени (допущение).
10. GitHub Pages включается один раз вручную в настройках репозитория (README, шаг 1).
