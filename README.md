# Лесная школа (kids-learning)

Учебные листы недели на планшетах детей — со своими медведями и капибарами — и уроки с ответами для родителя. Статический сайт (PWA) на GitHub Pages, работает без интернета после первой загрузки. Без рекламы, трекеров и регистрации.

ТЗ и принятые решения — [SPEC.md](SPEC.md). Формат недели — [docs/CONTENT_FORMAT.md](docs/CONTENT_FORMAT.md).

## Что где лежит и что видно публично

Репозиторий и сайт публичные. Поэтому:

- тексты уроков, имена детей, расписание и профили лежат **только зашифрованными** в `content/` (AES-256-GCM, ключ выводится из семейного пароля, PBKDF2-SHA256, 300 000 итераций);
- открыты только код приложения, `settings.json` (даты каникул и адрес синхронизации) и `content/manifest.json` (соль и список файлов без дат и имён);
- исходные тексты недели живут только в `.work/` (закрыто в `.gitignore`) и на Google Drive;
- семейный пароль нигде не записан: при сборке он берётся из переменной окружения `FAMILY_PASSWORD`, на планшете — вводится один раз и хранится на этом устройстве.

PIN-коды профилей (4 цифры) только разделяют профили на планшете и не защищают материалы.

## Настройка — один раз

### 1. Включить GitHub Pages

GitHub → репозиторий `kids-learning` → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → **Save**. Через 1–2 минуты сайт откроется по адресу `https://a9032034822-byte.github.io/kids-learning/`.

### 2. Задать семейный пароль для сборки

В Claude Code (облачная сессия): меню облачного окружения в заголовке сессии → **Edit** → переменные окружения → добавить `FAMILY_PASSWORD` = семейный пароль (не короче 12 символов). Новая сессия подхватит его. Пароль не присылать в чат и не писать в файлы.

Запишите пароль в надёжное место: без него материалы не расшифровать, восстановить его нельзя.

### 3. Поставить на планшет

1. Откройте адрес сайта: на iPad — в Safari, на Android — в Chrome.
2. iPad: **Поделиться** → **На экран «Домой»**. Android: меню **⋮** → **Установить приложение** (или «Добавить на главный экран»).
3. Откройте иконку «Лесная школа» с главного экрана. Родитель вводит семейный пароль — один раз на этом планшете.
4. На первом устройстве задайте PIN-коды для всех трёх профилей. Если синхронизация настроена, на остальных устройствах PIN придут сами.

### 4. Синхронизация прогресса (Cloudflare, бесплатно)

Без неё всё работает, но прогресс остаётся на том планшете, где его сделали, и родитель видит только своё устройство. С ней детские планшеты отправляют прогресс, а вход родителя его показывает. Сервер хранит только зашифрованные блоки.

1. Зарегистрируйтесь на **dash.cloudflare.com** (бесплатный тариф, нужна только почта).
2. Слева: **Storage & Databases** → **KV** → **Create** (Create a namespace) → имя `kids-learning` → **Add**.
3. Слева: **Workers & Pages** → **Create** → **Create Worker** (шаблон «Hello World») → имя `kids-learning-sync` → **Deploy**.
4. На странице воркера → **Edit code**. Удалите весь текст и вставьте содержимое файла [`worker/sync-worker.js`](worker/sync-worker.js) → **Deploy**.
5. Вернитесь к воркеру → **Settings** → **Bindings** → **Add** → **KV namespace** → Variable name: `KIDS`, KV namespace: `kids-learning` → **Deploy** (или **Save**).
6. Скопируйте адрес воркера вида `https://kids-learning-sync.<ваше-имя>.workers.dev` и откройте его в браузере — должно быть написано `kids-learning sync: ok`. Если написано «KV KIDS не привязан» — повторите шаг 5.
7. GitHub → файл [`settings.json`](settings.json) → карандаш **Edit** → в строке `"syncUrl": ""` вставьте адрес между кавычками → **Commit changes**.
8. На каждом планшете закройте и снова откройте приложение. Проверка: вход родителя → **Настройки** → «Синхронизация» — время последней синхронизации; зелёная точка вверху.

Бесплатного лимита Cloudflare (1 000 записей и 100 000 чтений в день) хватает с большим запасом. Названия кнопок на сайте Cloudflare иногда меняются — ищите по смыслу (KV, Worker, Bindings).

## Каждую неделю

### Автоматически — задание по расписанию (routine)

Уже настроено: routine «Лесная школа: сборка недели» — каждую **пятницу в 20:51** по местному времени. Оно будит сессию, в которой приложение настраивали, а та запускает новую сессию сборки (у новой сессии есть коннектор Google Drive и `FAMILY_PASSWORD`). Если routine пропал — создайте его заново в Claude Code (пятница вечером, новая сессия в этом репозитории, окружение с `FAMILY_PASSWORD`, коннектор Google Drive, право пушить в `main`) с этим текстом задания:

```text
Ты — еженедельная сборка приложения «Лесная школа» (репозиторий a9032034822-byte/kids-learning, ветка main).

1. Прочитай README.md, SPEC.md и docs/CONTENT_FORMAT.md.
2. Проверь переменную окружения FAMILY_PASSWORD. Если её нет — ничего не коммить и в итоге напиши одной строкой, что её нужно задать в настройках окружения.
3. Следующая неделя = понедельник–воскресенье после сегодняшнего дня (по местному времени семьи). Если её понедельник попадает в каникулы из settings.json — ничего не делай и закончи.
4. Через коннектор Google Drive открой папку «УЧЁБА/09 Приложение» и найди в ней подпапку «Неделя NN (даты)», чьи даты попадают на следующую неделю. Нет такой папки — ничего не делай и закончи.
5. В папке 4 документа: «РАСПЕЧАТКА_Неделя N_<ИМЯ> (текст для приложения)» и «УРОКИ_Неделя N_<ИМЯ> (для родителя)» на каждого ребёнка. Прочитай каждый (read_file_content) и сохрани текст как есть в .work/week-NN/src/<точное название документа>.md.
6. Файл «УЧЁБА/09 Приложение/ПРИЛОЖЕНИЕ_семья (family.json)» (профили детей и их персонажи) сохрани как .work/week-NN/family.json, а «УЧЁБА/09 Приложение/ПРИЛОЖЕНИЕ_ролики (videos.json)» (ролики к песням), если он есть, — как .work/week-NN/videos.json.
7. Если в папке недели есть файл «ПРИЛОЖЕНИЕ_Неделя N (week.json)» — сохрани его как .work/week-NN/week.json. Иначе составь .work/week-NN/week.json строго по docs/CONTENT_FORMAT.md: все предметы и все страницы распечатки, ответы — только из УРОКИ-файлов, ничего не придумывать; что не получается сделать интерактивным — страницей распечатки или заданием «в тетради». Готовый week.json положи в ту же папку Drive под именем «ПРИЛОЖЕНИЕ_Неделя N (week.json)».
8. node tools/kl.mjs check .work/week-NN — исправь все ошибки.
9. node tools/kl.mjs build .work/week-NN, затем node tools/kl.mjs verify и npm test — всё должно пройти.
10. git status: изменения только в content/. Ничего из .work/ и никаких открытых текстов, имён детей и расписания не коммитить. Коммит «Неделя NN: контент», push в main.
11. В итоге — 2–3 строки: какая неделя собрана, сколько заданий у каждого ребёнка, предупреждения сборщика.
```

Для **первой недели** (29.09–02.10) запустите то же задание один раз вручную, заменив шаг 3 на «неделя = папка «Неделя 01 (29.09–02.10)»». Готовый `week.json` для неё уже лежит в этой папке на Drive.

### Недели 2–15 уже подготовлены

В папках «УЧЁБА/09 Приложение/Неделя 02 … 15» лежат черновики (по программам на Drive): 2 распечатки, 2 файла уроков и готовый «ПРИЛОЖЕНИЕ_Неделя N (week.json)». Пятничная сборка берёт их сама. Что проверить маме — «УЧЁБА/09 Приложение/ПРОВЕРИТЬ_Недели 02–15 (для мамы)». Поправили документ — поправьте и week.json или удалите его (тогда сборка составит новый по документам) и попросите «пересобери неделю NN».

### Вручную

1. Сессия Claude Code в этом репозитории с `FAMILY_PASSWORD` и коннектором Google Drive: «Собери неделю NN по README» — дальше шаги 4–10 выше.
2. Или на своём компьютере (Node 20+):

```bash
mkdir -p .work/week-02/src               # положите сюда 4 документа в Markdown (Файл → Скачать → Markdown)
# положите .work/week-02/family.json (профили детей) и напишите .work/week-02/week.json по docs/CONTENT_FORMAT.md
node tools/kl.mjs check .work/week-02
FAMILY_PASSWORD='…' node tools/kl.mjs build .work/week-02
FAMILY_PASSWORD='…' node tools/kl.mjs verify
git add content && git commit -m "Неделя 02: контент" && git push
```

Добавление недели — это только новые файлы в `content/`, код не меняется. Приложение само показывает текущую неделю по датам, прошлые — в «Прошлых неделях». Повторная сборка той же недели заменяет её.

Прочие команды: `node tools/kl.mjs list` — недели; `remove <ГГГГ-ММ-ДД>` — убрать неделю; `rekey` — сменить пароль (`OLD_FAMILY_PASSWORD` → `FAMILY_PASSWORD`, потом пароль вводится заново на каждом планшете).

## Персонажи детей

У каждого профиля свой персонаж и цвет — по ним дети находят свою карточку на экране «Кто сегодня учится?»: у старшей — **панда**, у младшего — **капибара**, у родителей — большой медведь в очках. Меняется в файле «УЧЁБА/09 Приложение/ПРИЛОЖЕНИЕ_семья (family.json)» на Drive (поля `companion`, `companionName`, `color`) и вступает в силу со следующей сборкой недели.

## Ролики к песням

Песни французского — с роликами YouTube: в задании «🎵» у ребёнка кнопка «▶ La chanson», плеер открывается прямо в приложении (нужен интернет). Родитель видит ролики недели ссылками в «Уроках» — можно посмотреть заранее. Список по неделям — «УЧЁБА/09 Приложение/ПРИЛОЖЕНИЕ_ролики (videos.json)» на Drive: поменяйте ссылку у нужной недели, и следующая сборка возьмёт её (уже собранную неделю — «пересобери неделю NN»). Формат — [docs/CONTENT_FORMAT.md](docs/CONTENT_FORMAT.md#ролики-к-песням-youtube).

## Каникулы

В [`settings.json`](settings.json): `"holidays": [{ "from": "2026-12-21", "to": "2027-01-01", "title": "Зимние каникулы" }]` (даты — из программ на Drive). `to: null` — если конец не известен. Другие каникулы добавляются так же, отдельной строкой. В каникулы уроков нет, серия дней не сгорает, ребёнку предлагается повторение пройденного, еженедельная сборка ничего не делает.

## Для разработки

- Без сборки и зависимостей: ES-модули в `src/`, стили в `styles.css`, service worker `sw.js`.
- Локально: `npm run serve` → `http://localhost:8080/`; подменить дату: `?today=2026-09-30`.
- Проверки: `npm test` (шифрование, разбор недели, слияние прогресса, сборка вымышленной недели из `docs/example/`).
- Локальный сервер синхронизации: `node tools/dev-sync-server.mjs` (код воркера, память вместо KV).
- Поменяли файлы приложения — поднимите `VERSION` в `sw.js`; `node tools/kl.mjs check-shell` проверит список файлов для офлайна.
- Иконки: `node tools/make-icons.mjs` (нужен Playwright).

```
index.html, styles.css, sw.js, manifest.webmanifest, settings.json
src/            приложение: app.js, crypto.js, store.js, sync.js, content.js, characters.js …
src/screens/    вход, выбор профиля, экран ребёнка, прохождение урока, экран родителя
src/tasks/      типы заданий: rule, choice, input, fix, split, stress, column, sort, read, poem, offline, page
content/        зашифрованный контент (собирается tools/kl.mjs)
tools/          сборщик недели, самопроверка, иконки, локальный сервер синхронизации
worker/         Cloudflare Worker для синхронизации
docs/           формат недели и вымышленный пример
```
