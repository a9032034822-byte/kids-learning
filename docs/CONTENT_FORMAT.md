# Формат недели (week.json)

Неделя собирается из папки вне git — `.work/week-NN/`:

```
.work/week-NN/
  week.json          ← задания недели (этот формат)
  src/               ← тексты 4 документов с Google Drive, как есть (Markdown)
    РАСПЕЧАТКА_Неделя N_<ИМЯ> (текст для приложения).md
    УРОКИ_Неделя N_<ИМЯ> (для родителя).md
```

Сборщик сам берёт из `src/`:
- **страницы распечатки** — из РАСПЕЧАТКА-файла, по меткам `— стр. N —`. Они видны ребёнку в «Страницах распечатки» и в заданиях `page` / `offline` с полем `page`. Так ничего из распечатки не теряется, даже если не стало интерактивным;
- **уроки для родителя** — УРОКИ-файл целиком (расписание, ход урока, ответы) → экран «Уроки» у родителя.

Файл ищется по слову `РАСПЕЧАТКА` / `УРОКИ` и ключу ребёнка в имени. Если имя другое — укажите `printout` / `lessonsDoc` у ребёнка.

Проверка без пароля: `node tools/kl.mjs check .work/week-NN`.
Сборка: `FAMILY_PASSWORD=… node tools/kl.mjs build .work/week-NN`.

## Верхний уровень

```json
{
  "week": 2,
  "from": "2026-10-06",
  "to": "2026-10-09",
  "title": "Неделя 2",
  "family": { "kids": [ … ] },
  "kids": { "<КЛЮЧ>": { … }, "<КЛЮЧ>": { … } }
}
```

- `from` / `to` — первый и последний учебный день (ГГГГ-ММ-ДД). `from` — идентификатор недели: повторная сборка с тем же `from` заменяет неделю.
- `<КЛЮЧ>` — имя ребёнка **как в названии документов** (например, то, что стоит после `Неделя N_`).
- `family` — нужен только при первой сборке или чтобы поменять профиль. Потом профили хранятся в зашифрованном `content/index.enc`.

```json
{ "key": "<КЛЮЧ>", "name": "Имя", "gender": "f", "age": 10,
  "companion": "capybara", "companionName": "Капа",
  "color": "#B388EB", "accent": "#FF9F1C", "uiLang": "ru" }
```

`companion`: `capybara` или `bear`. `uiLang` — язык «рамки» экрана ребёнка (`ru` / `en`); внутри предмета язык всегда язык предмета.

## Ребёнок

```json
{
  "poem": {
    "author": "Автор", "title": "«Название»",
    "stanzas": [["строка", "строка", "строка", "строка"], ["…"]],
    "glossary": [["слово", "значение"], ["два слова", "значение"]]
  },
  "days": [
    { "date": "2026-10-06", "lessons": [ { …урок… } ] }
  ]
}
```

## Урок

```json
{ "time": "08:30–09:00", "subject": "ru", "title": "Название урока", "tag": "Сама", "tasks": [ … ] }
```

- `subject`: `ru` русский, `lit` литература/стих, `math` математика (на русском), `en` английский, `sci` наука, `logic` логика, `fr` французский, `other` прочее (мини-контроль).
- `time` — необязательно (урок без времени, например «Стихотворение недели» в конце дня).
- `tag` — короткая пометка на дорожке: «Сама», «С мамой», «Вместе с …», «On my own».

## Задания

Общие поля (необязательные): `title` — подпись на дорожке; `lang` — язык задания, если не совпадает с предметом (`ru` / `en` / `fr`); `page` — номер страницы распечатки (кнопка «Страницы»); `id` — стабильный id (по умолчанию `<дата>-<урок>-<задание>`; не меняйте порядок заданий в уже начатой неделе).

| type | Что это | Поля |
|---|---|---|
| `rule` | Правило «Видишь / Пишешь / Почему». Если в `see` есть «(вариант / вариант)», ребёнок выбирает, потом видит объяснение. Без вариантов — «Как правильно?» → объяснение. | `name`, `text`, `see`, `write`, `why`, `answer?` (текст или номер верного варианта; по умолчанию — тот, что встречается в `write`; если оба — укажите явно) |
| `choice` | Выбор из вариантов | `q`, `items: [{q, options, answer, why?, say?}]` или одним вопросом `q, options, answer` |
| `input` | Вписать ответ | `q`, `items: [{q?, a, suffix?}]`; несколько полей: `{q, fields: [{label, a}]}`; диктант: `{say: "двести восемь", a: "208"}` — приложение произносит `say`. `a` может быть массивом вариантов. Числа сравниваются без пробелов, слова — без учёта регистра и ё/е. |
| `fix` | Найди и исправь ошибки | `q`, `text`, `mistakes: [{wrong, right}]` (`right` — строка или массив допустимых). `wrong` со знаком препинания («2024,») сравнивается целиком. Повторы слова находятся все. `answer` — исправленный текст для показа. |
| `split` | Раздели на предложения | `q`, `text` (как в распечатке, без точек), `answer` (с точками) |
| `stress` | Поставь ударение | `q`, `words: ["ко́шка", "ёжик"]` — знак ударения U+0301 после гласной; слово с ё можно без знака |
| `column` | Пример в столбик | `q`, `items: ["125 + 348", "600 − 275", "84 : 4"]` — ответ считает сборщик (деление — только нацело) |
| `sort` | Разложи по группам | `q`, `groups: [...]`, `items: [["слово", "группа"], …]`; `context: true` — показывать всё предложение (разбор по частям речи); третий элемент `"br"` — перенос строки |
| `read` | Чтение вслух | `q`, `cards: ["папа", {t: "53", say: "пятьдесят три", hint: "пятьдесят три"}]`, `rounds?`, `shuffle?`; или таблица `grid: [["ПА","ПО"],["ТА","—"]]` |
| `poem` | Стихотворение недели | `stage`: `read` (вт) · `part` (ср, `lines`: 4–8) · `hints` (чт) · `nohints` (пт, родитель подтверждает) |
| `offline` | Сделай в тетради | `q`, `details?` (можно с переносами `\n`), `timer?` (минуты), `count: "words"` (спросить число слов), `icon?`, `page?`, `approve: false` — если подтверждение родителя не нужно |
| `page` | Страница распечатки как есть | `page` (номер или массив), `q?` |

## Как переносить распечатку

1. Каждое правило «Видишь / Пишешь / Почему» → `rule` (варианты в скобках → выбор).
2. Упражнения с ответами из УРОКИ-файла → `choice` / `input` / `fix` / `split` / `stress` / `column` / `sort` с автопроверкой. Ответы берутся **только** из УРОКИ-файла — не придумывать.
3. Слоги, слова, числа «прочитай вслух» → `read` (для чисел — `hint` с записью словами).
4. Нарисуй, пропиши, диктант, письмо на время, опыт → `offline` (таймер, где есть время).
5. Всё, что не получилось сделать интерактивным, — `page` или `offline` со ссылкой на `page`.
6. Время и порядок уроков — из УРОКИ-файла (у каждого ребёнка своё расписание).
7. Стих недели — в `poem` ребёнка, плюс задания `poem` по дням: вт `read`, ср `part`, чт `hints`, пт `nohints`.
8. То, что ребёнок не должен видеть заранее (слова диктанта, ответы), в тексты заданий не писать.
